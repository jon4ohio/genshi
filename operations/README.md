# Operations

How organizations run, adopt, assess, and mature design system capability over time.

Operations canon **instantiates** metamodel operational entities (Capability, Assessment, Practice). It does not redefine foundation vocabulary.

**Boundary:** [canon-precedence](../../foundation/canon-precedence.md) — foundation defines structure; operations defines how programs run.
