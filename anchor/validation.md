# Validation

Anchor v0.2 is released. This repository participates in Anchor's open Evidence Window as an **independent adopter**—not a Reference Project.

## Validation status

Genshi already has its own assessment and maturity canon ([operations/assessment/](../operations/assessment/), [operations/maturity/](../operations/maturity/)). Anchor adoption tests whether a mature/src layer reduces repeated explanation across AI sessions **without** duplicating Genshi governance.

## Evidence window

The Evidence Window is **open**. Observations are recorded in [evidence/](evidence/) and may be shared via [Contributing Evidence](https://github.com/jon4ohio/anchor/blob/main/docs/experience/06-contributing-evidence.md).

## Current questions (Genshi-specific)

- Can Anchor's Entry + Handoff reduce re-orientation cost for contributors working across `foundation/`, `operations/`, and `design-system/`?
- Does responsibility mapping preserve Genshi canon precedence without file migration?
- Can Genshi's assessment framework assess the reference implementation without conflating it with framework maturity?
- Does BMAD (`.cursor/rules/bmad/`) compose as a companion capability without ownership conflicts?

## How to participate

1. Work from [project.md](project.md) and [handoff.md](handoff.md)
2. Record observations in [evidence/](evidence/)
3. Share findings to Anchor governance channels when ready
