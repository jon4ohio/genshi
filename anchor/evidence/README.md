# Evidence

Observations from Genshi's Anchor adoption and framework assessments.

## How to capture

Follow the framework [Observation Guide](https://github.com/jon4ohio/anchor/blob/main/docs/experience/templates/observation-guide.md) when useful.

Local structure:

1. **Describe the observation** — context and what happened
2. **Link to sources** — repository paths, issues, PRs
3. **Note implications** — for Genshi and/or Anchor (without overstating certainty)
4. **Date the entry** — `YYYY-MM-DD-short-title.md`

## Genshi assessments

Framework health assessments use Genshi's own instrument: [operations/assessment/framework.md](../../operations/assessment/framework.md). Store assessment instances here; do not duplicate dimension definitions.

## Share upstream

Share Anchor-relevant findings via [Contributing Evidence](https://github.com/jon4ohio/anchor/blob/main/docs/experience/06-contributing-evidence.md).
