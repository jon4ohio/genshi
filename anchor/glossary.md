# Glossary

Project-local terms for Anchor coordination in this repository. **Genshi framework vocabulary** lives in [foundation/glossary/](../foundation/glossary/). **Anchor framework vocabulary:** [Anchor Experience glossary](https://github.com/jon4ohio/anchor/blob/main/docs/experience/glossary.md).

| Term | Meaning |
|------|---------|
| **Genshi** | Design system framework canon in `foundation/`, `operations/`, `evolution/` |
| **Reference implementation** | `design-system/` — v0.1 consumer; not framework canon |
| **Framework canon** | Normative layers per [canon-precedence](../foundation/canon-precedence.md) |
| **Anchor** | Coordination framework for shared project understanding |
| **Entry** | Anchor Project Entry — [project.md](project.md) |
| **Evidence Window** | Open Anchor validation period for independent adopters |
| **Companion capability** | External methodology (e.g. BMAD) that composes without owning project truth |
