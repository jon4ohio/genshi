# Knowledge Asset

## Definition

An artifact whose primary value is committed organizational knowledge—meaning, rationale, and constraints—rather than executable behavior alone.

## Why It Matters

Machine-readable knowledge must be distinguishable from presentation and code. Without this class, tokens collapse into theme variables and governance has nothing durable to attach to.

## Relationships

- **artifact** — every knowledge-asset is an artifact; not every artifact is a knowledge-asset
- **token** — primary design-knowledge specialization
- **decision** — knowledge-assets must link to decisions that justify their semantics
- **meaning** — knowledge-assets encode and carry meaning
- **component** — may be an artifact but is not knowledge-primary; it consumes knowledge via tokens

## Common Misinterpretations

- Calling any documentation file a knowledge-asset without ownership, lifecycle, or decision linkage
- Equating knowledge-assets with documentation websites (presentation is not the asset)
- Treating raw platform values (hex, px) as knowledge-assets without semantic commitment

## Genshi Interpretation

Tokens are knowledge assets (Principle 04). [Content rules](content-rule.md) and [accessibility rules](accessibility-rule.md) are knowledge-primary specializations. Platform aliases are subordinate exports, not knowledge-assets themselves.
