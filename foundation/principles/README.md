# Principles

Non-negotiable beliefs and decision tests that guide framework interpretation and adoption. Each principle is a first-class artifact: one file, one number, independently versionable.

**Upstream:** [Manifesto](../thesis/manifesto.md)  
**Governed by:** [ADR-0001](../../evolution/decisions/ADR-0001-why-genshi-exists.md)

## How to read

1. Read the **Statement** — if you disagree here, Genshi is not aligned with your intent.
2. Read **Implications** and **Anti-patterns** before changing process or tooling.
3. Use **Examples** as illustrations, not exhaustive rules.

Principles change through [enhancements](../../evolution/enhancements/) and, when binding scope shifts, a superseding ADR. Do not silently edit **Stable** principles; mark experimental principles in this index.
