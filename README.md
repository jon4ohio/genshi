# Genshi

Design System Framework — organizational systems for designing, governing, scaling, operating, and evolving design systems.

Technology agnostic. Governance driven. Architecture first.

## Repository structure

| Area | Purpose |
|------|---------|
| [`foundation/`](foundation/) | Thesis, principles, metamodel, governance |
| [`system/`](system/) | Tokens, components, patterns, accessibility, content |
| [`operations/`](operations/) | Lifecycle, adoption, assessment, maturity |
| [`evolution/`](evolution/) | Enhancements, decisions, releases |
| [`docs/`](docs/) | Published documentation portal |

No implementation code in this repository. Reference implementations and tooling may follow in later phases.
