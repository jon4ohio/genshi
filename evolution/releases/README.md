# Releases

Framework versioning, changelogs, compatibility notes, and release process.

## Current version

**Framework v0.2.0** — see [CHANGELOG](CHANGELOG.md).

## Versioning policy

- **Major (x.0.0):** Breaking changes to principles, metamodel entity set, or canon precedence rules
- **Minor (0.x.0):** New canon layers, ADRs, operations frameworks, or glossary expansions
- **Patch (0.0.x):** Governance files, documentation corrections, non-substantive fixes

Framework version is independent of any future npm packages or tooling.

## Tags

Releases are tagged on `main` as `v0.x.y` (e.g. `v0.2.0`).
